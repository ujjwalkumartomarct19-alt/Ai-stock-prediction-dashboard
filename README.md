# 🚀 AI Stock Prediction Dashboard

An end-to-end Machine Learning project that predicts stock prices and provides data-driven investment insights through an interactive Streamlit dashboard.

---

## 📊 Features

- 📈 Real-time stock data using Yahoo Finance API
- 🔍 Feature engineering (MA10, MA50, returns)
- 🤖 Multiple ML models:
  - Linear Regression
  - Random Forest
  - XGBoost
- 🧠 Automatic best model selection (based on MAE)
- 💡 BUY / SELL / HOLD recommendation system
- 📊 Interactive stock visualization (Plotly)
- 🏆 Top 5 stock recommendations
- ⚡ Clean and animated UI using Streamlit

---

## 🛠 Tech Stack

- Python
- Streamlit
- Scikit-learn
- XGBoost
- Plotly
- Pandas & NumPy
- yFinance API
